# Legacy scripts

Unmodified copies of superseded/exploratory scripts from the original
analysis, kept only for historical reference. **None of these are part of
the figure-reproduction pipeline** — see the top-level README for what is.

- `20250919_summarizeDE.Rmd` — an earlier complete draft of the figure
  assembly logic that became `figures/*.Rmd`; superseded once the final
  analysis (what this repo reproduces) was run.
- `20250919_cutouts.Rmd` — scratch/development work done just before
  finalizing the figure assembly script; superseded output.
- `20250919_addFigs.Rmd` — an unrelated bulk RNA-seq comparison plot, not
  scRNA-seq, not part of any manuscript figure this repo reproduces.

These still reference absolute cluster paths from the original analysis
environment and will not run as-is.
